# Support Guide

Welcome to the SideQuest Support Guide. Below is a map of channels to get help, report issues, or suggest improvements.

---

## 🐛 Bug Reports

If you encounter technical issues or page layout glitches:
1. Search active [GitHub Issues](https://github.com/Eraiyamuthan-P/SideQuest/issues) to verify if the bug is already logged.
2. If new, open a ticket using the **Bug Report** template inside the repository's `.github/ISSUE_TEMPLATE` guidelines.

---

## ⚖️ Disputes & Moderation

For transaction issues or credit lock disputes between students:
- Head over to the `/support` portal in the web application and submit a **Dispute Ticket**.
- A moderator or administrator will inspect the chat logs and task milestones, then adjust user credits accordingly.

---

## 💡 Feature Suggestions

Have ideas for new campus blocks or notification formats?
- Open a GitHub issue using the **Feature Request** template.
- Clearly describe your request, the campus problem it solves, and mockups if applicable.
