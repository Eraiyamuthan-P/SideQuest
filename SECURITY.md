# Security Policy

We take the security and privacy of SideQuest users seriously. This document outlines vulnerability reporting guidelines.

---

## Supported Versions

| Version | Supported |
| ------- | --------- |
| v1.0.x  | ✅ Yes    |
| < v1.0  | ❌ No     |

---

## Reporting a Vulnerability

Please **do not** log security vulnerabilities in GitHub Issues. Instead, email reports directly to:

**eraiyamuthan.p2023@vitstudent.ac.in**

### What to Include
- Detailed description of the vulnerability.
- Steps to reproduce (including scripts, payloads, or screenshots).
- Potential impact vectors.

---

## Response Expectations
- **Triage**: Within 48 hours.
- **Remediation**: A fix will be developed and released within 7 business days for verified critical flaws.
